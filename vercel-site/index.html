Connect the full Streamlit app (one time):

  1. Push code to GitHub: Huseynitsu/kaslu-lab (git push origin main).
  2. Open share.streamlit.io → New app → pick that repo → main file streamlit_app.py.
  3. After deploy, open your app URL (e.g. https://….streamlit.app). Optional: add ?app=YOUR_URL to this page to show an Open app button.

Local run: .\scripts\run-app.ps1 → localhost:8501
